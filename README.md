# Quick-Access-Dashboard
NOTE The Quick Access Dashboard has been tested on Windows, iMac and Linux Computers 

Download the Quick Node Dashboard zip file to your computer.

Make sure you know what directory you save it to. 

Click the file and unzip it.

Click on the HTML Document

Click Add Node

Both Header lines at the top are now editable. Enter what you want to call this access page.

In the top entry line, enter you node number

In the Name Field, Name it what you want it to show on the dashboard

You will then see entries for the IP address of the Allmon3 or Supermon and Allscan

There is also an Optional entry line, You can name this what you wish with the IP address associated with it.

Enter the IP address of each of these URLS

Once IP's are entered click Save node.

NOTE
These fields can be anything you wish to enter, 
You can add the IP address of your Hotspots as well for quickly pulling them up.

NOTE: You can enter any entry for a site you want in an access box. Just fill in the info you need to get there.
