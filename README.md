# Quick-Node-Hotspot-Dashboard
Download the Quick Node Hotspot Dashboard html files
Save it to your computer in the directory of your choosing. 
Click the file and open it.
Click Add Node
In the top entry line, enter you node number
In the Name Field, Name it what you want it to show on the dashboard
You will then see entries for the IP address of the Allmon3 or Supermon and Allscan
Enter the IP address of each of these URLS
Once IP's are entered click Save node.
NOTE
These fields can be anything you wish to enter, 
You can add the IP address of your Hotspots as well for quickly pulling them up.
